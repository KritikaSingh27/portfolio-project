# Kritika Kumari — Personal Portfolio

A clean, responsive personal portfolio website built with pure HTML, CSS, and JavaScript — no frameworks, no libraries.

🔗 **Live Site:** [project-portfolio-kritika.vercel.app](https://project-portfolio-kritika.vercel.app/)

---

## About the Project

This is my personal portfolio website that showcases who I am, the skills I have, and the projects I've built. It's designed to be fast, accessible, and easy to navigate on any device — mobile, tablet, or desktop.

The design follows a **Modern Tropical Floral Minimalism** theme with a deep plum and rose gold colour palette.

---

## Sections

| Section | What's inside |
|---------|--------------|
| **Home** | A quick intro — my name, role, and a short tagline |
| **About** | Background, education, and what I'm currently working on |
| **Skills** | Technologies I work with — languages, frameworks, tools |
| **Projects** | Three projects with live demo and source code links |
| **Contact** | Footer with links to my email, LinkedIn, GitHub, and X |

## Tech Stack

- **HTML5** — semantic, accessible markup
- **CSS3** — custom properties, Flexbox, Grid, responsive design
- **JavaScript (Vanilla)** — no frameworks or libraries
- **Fonts** — Cormorant Garamond + Plus Jakarta Sans (via Google Fonts)
- **Deployed on** — [Vercel](https://vercel.com/)

---

## Features

- ✅ Fully responsive — works on all screen sizes
- ✅ Accessible — keyboard navigation, ARIA labels, skip link, semantic HTML
- ✅ Sticky header with scroll-aware styling
- ✅ Mobile hamburger menu (closes on tap, Escape key, or outside click)
- ✅ Active section highlighting in the navbar as you scroll
- ✅ Smooth scroll-to-top button in the footer
- ✅ Respects `prefers-reduced-motion` for users who prefer less animation
- ✅ No external JavaScript dependencies
